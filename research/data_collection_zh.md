# 无人机到货前的数据采集方案

2026 年 10 月 29 日更新。首轮演示采用用户选定的贴墙打印图。任务是识别图中的物品类别、对准后靠近墙面并停止。该演示能验证打印目标接近，不能直接证明对真实三维物体的泛化能力。

## 先分清两个训练问题

检测器用有 bounding box 标签的图像训练；视频提供不同距离、角度、曝光和遮挡下的样本。先测试 COCO 预训练 YOLO11n，若对打印图片已足够可靠，不必从零训练。需要适配时再微调。

PPO 用能响应动作的闭环仿真训练。环境每 0.1 秒接收前进与转向动作，更新位置、朝向，再产生带延迟和噪声的检测框、前向 ToF。手机视频用来验证检测、测量框抖动与掉检，以及配置仿真的噪声；视频回放不是 PPO 的可交互环境。没有真实动作标签与系统辨识，也不能把手持相机的轨迹当成 TT 动力学。

## 一次采集怎么拍

建议起步选 2–3 个 COCO 类别，例如瓶子、背包、杯子，每类 3–5 张不同图片，印在 A3 哑光纸上。图中的目标尽量占纸面大部分，避免一张图同时出现多个目标。最终类别以预训练检测测试结果确定；纸张大小不是检测框的实际大小。

把打印图中心贴在预期摄像头高度，用卷尺在墙前标出 0.4、0.5、0.65、0.8、1.0、1.2、1.5、2.0、2.5 和 3.0 米。距墙定义从相机/ToF光学基准测量，同时记录外壳到墙的实际净距。近距离点用手持设备采集，不代表飞行许可。

手机横屏 16:9，1080p 或 720p，30 fps，主摄 1×，禁用数字变焦；记录是否启用电子防抖、HDR、自动曝光。用小推车或固定高度手柄模拟前进、停止和转向，避免只拍平稳的正面视频。手机视场和 TT 不同，保留原视频，之后用相机标定或裁剪匹配视场；不要把厂商对角视场直接当作水平视场。

每段 20–40 秒，每类约 15–25 段作为第一批目标，而非保证足够的样本量。覆盖正面接近、左右偏航、侧向偏移、越过最佳停止点、突然停住、短遮挡、出画再入画、半张图截断、目标缺失、两个同类目标、旁边相似海报。采集不同墙面、房间、灯光、日期；加 20–30% 无目标和干扰片段。墙面应有漫反射区域，亮膜与玻璃单独作为困难条件。

保持每个距离点 2–3 秒，记录距离区间；移动过程中不要把一个手填常数距离复制给所有帧。如果手机带深度功能，它的数据也需要标定和有效性检查，不能自动当作可靠真值。卷尺的静止点最适合作为首轮视觉尺度校准。

## 标签与数据划分

先以 1–2 fps 抽帧，优先保留距离变化、偏航、模糊和遮挡帧。给图内物品画框，不给整张纸画框；纸框若作为另一个类别，需要明确另行标注。初始目标约 1,000–2,000 张人工复核图片，先看学习曲线和失败案例再扩充。

`data/clips.example.csv` 是登记模板。每个片段记录 print_id、room、device、class、lighting、trajectory、group_id。按采集场次/房间/打印图族分组划分 train/val/test；同一视频的相邻帧不能随机分到不同集合。默认 70/15/15 是起点，少量分组时手工确保每个集合覆盖类别。若想声称泛化到新图片，测试集必须使用未参与训练的打印图片；同一幅源图的换尺寸打印应属于同一图族。

```powershell
python -m objectpilot.data extract --manifest data/clips.csv --out data/frames/batch01 --fps 2
# 在 CVAT 或其他标注器中导出 YOLO 标签，人工审核，并在 frames.csv 填 label_path / label_reviewed=yes。
python -m objectpilot.data prepare --frames data/frames/batch01/frames.csv --out data/dataset/v1 --classes bottle,backpack,cup
python -m objectpilot.data train --data data/dataset/v1/dataset.yaml --weights yolo11n.pt --epochs 50 --device cpu
```

空标签文件只能用于已确认的负样本；缺失标签不是负样本。整理脚本会拒绝未复核标签、越界框、重复图片和分组泄漏。它无法自动发现不同图片但同一场景的近重复，需要正确登记 group_id 和人工复核。

检测指标包括逐类 precision/recall、mAP50–95、远中近距离分桶 recall、最长连续掉检时间、误选率、推理延迟 median/p95。固定置信阈值后再跑保留测试集；不要只看训练 loss。真实墙面视频尚未提供，因此本次没有伪造训练集或报告真实检测性能。

## 距离与模型选择

首版不需要额外训练单目深度网络。对固定打印图，在多个已知距离上拟合 `k = median(distance_m × bbox_height_fraction)`，运行时 `visual_distance = k / bbox_height_fraction`。这是每张打印图、打印尺寸、相机和视场特定的粗略代理；目标姿态、裁切、遮挡和不同图片会破坏它。`objectpilot-data calibrate` 只接受单独的 calibration 集。

ToF 近处接管。打印图贴墙时传感器测的是墙面沿光轴的距离，斜着看墙时不等于垂直墙距；先对准、减速，再进入停止阶段。真实物体时还要标定摄像头与传感器视场重叠以及前后安装偏移。原始近障碍读数始终能触发停止，即使它未被关联到检测目标。

## 公开数据怎么用

[COCO](https://cocodataset.org/) 和已有预训练权重是识别常见物体的起点。直接下载完整数据集并不是现在的首要工作。打印域的反光、网点、边框、贴墙背景和近距离裁切必须靠自采数据覆盖。

[VisDrone](https://github.com/VisDrone/VisDrone-Dataset) 主要是航拍车辆、行人等场景，与室内平视贴墙图接近差异较大，适合作为补充困难样本研究，不作为本任务主训练集。本次检索没有找到可直接替代本实验的 TT 贴墙图像、前向测距和动作同步数据集；这不是不存在此类数据的证明。项目应发布自己的可复现记录格式和脱敏样例。

## 到货后的补采

先拆桨/静置记录 TT 相机和 ToF，重做相机尺度校准、视场重叠、畸变和近距离测试；再测视频整体延迟、SDK响应、刹停和不同电量的差异。主机收到帧的时刻不是拍摄时刻，可以拍显示时钟/闪灯对整体延迟做独立估计。

补一批真实 TT 图像，把模型从手机域适配到无人机域。更新仿真增益、响应时间常数、动作/观测延迟、掉帧和传感器失效分布，重新训练或验证 PPO。三个训练种子，共享保留仿真起点；允许的硬件阶段再做配对 PID/PPO 试验。若 PID 更可靠，正式演示使用 PID，论文如实报告。
